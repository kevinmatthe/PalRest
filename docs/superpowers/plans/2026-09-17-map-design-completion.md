# 地图设计遗漏项补齐 Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development; independently review the result against the approved design and verify before signing.

**Goal:** 补齐已认可地图设计中的等级/经验成长曲线、成长里程碑、浮窗近期变化，并准确记录计划与验收状态。

**Architecture:** 在既有 progress JSON 契约追加 level、experience 两项计数，保留旧四项和缺失状态；复用已验证的 checkpoint 差分/回档边界。前端沿用观察窗口和历史游标，只展示可复核的变化。里程碑采用实际等级提升、图鉴/传送点新增，不引入任意奖励阈值，也不将区间变化绑定到玩家位置。

**Tech Stack:** 现有 Python Worker、Go/SQLite、React/TypeScript/Leaflet；不新增依赖。
